# Font licences

Both faces are licensed under the SIL Open Font License, Version 1.1
(OFL-1.1). The files in this folder are Latin subsets of the variable
fonts published in the Google Fonts repository, produced with fontTools
(`pyftsubset` after `varLib.instancer`) on 7 September 2026. The
OFL permits subsetting and redistribution; neither file is sold on its
own, and the Reserved Font Names are kept. The full licence text of each
family follows, copied verbatim from the `OFL.txt` beside the font in
the Google Fonts repository.

Source Sans 3 draws tabular lining figures by default (every digit has
the same advance width), and Source Serif 4 carries the `tnum` feature;
`assets/atlas.css` requests tabular figures wherever numbers align.
